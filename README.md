# 數感特攻隊

## 專案目的

這是一個提供國中學生使用的數學心算練習網頁，主要使用者為國一升國二學生。

開發目的不是取代正式課程教學，而是透過重複練習與錯誤訂正，協助學生提升基本運算速度、正確率與熟練度。

## 使用方式

本專案目前為單一網頁程式，程式集中於 `index.html`。

目前透過 Vercel 部署成網頁，方便學生直接使用瀏覽器開啟練習。

支援手機、平板與桌機瀏覽器；其中手機與平板是主要使用情境。

使用者可在首頁選擇四種心算挑戰主題，並選擇 10 題、20 題或 30 題進行練習。

## 目前功能

* 提供四種心算挑戰主題。
* 隨機產生練習題目。
* 第一階段可直接輸入答案作答。
* 第一階段答錯後，會展開第二階段逐步訂正，引導學生完成正確解法。
* 支援分數等值答案判定。
* 支援畫面上的虛擬鍵盤，也支援電腦實體鍵盤輸入。
* 顯示目前題目進度，以及首次答對題目的星星標記。
* 結果頁會顯示總題數、首次答對題數與經引導後答對題數。
* 結果頁會顯示總作答時間及平均每題時間。
* 依不同題型的錯題數，產生本次測驗的盲點診斷。
* 同一道題在第二階段重複答錯，不會重複增加錯題數。
* 手機版支援動態視窗高度、裝置安全區與中間內容捲動，提升手機與平板操作穩定性。

## 本階段已完成改善

* 修正手機與平板畫面裁切及按鈕無法操作問題。
* 改善手機字體可讀性、題目區與虛擬鍵盤尺寸。
* 修正比例式部分分支的交叉相乘引導錯誤。
* 將比例式引導改為連續顯示原式、交叉相乘、除法及求 x。
* 修正盲點診斷重複累計同一道題錯誤送出的問題。

## 目前已知限制

* 尚未儲存跨次練習的歷史答題與錯題紀錄。
* 盲點診斷只分析本次測驗。
* 不同類別錯題數相同時，目前只會顯示其中一個盲點。
* 桌機版仍以手機型窄版練習畫面為主。
* 程式目前集中於單一 `index.html`，功能增加後可能需要拆分。

## 後續改善方向

* 依實際使用回饋調整題目難度與分布。
