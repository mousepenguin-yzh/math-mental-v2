# 數感特攻隊

## 專案目的

這是一個提供國中學生使用的數學心算練習網頁，主要使用者為國一升國二學生。

開發目的不是取代正式課程教學，而是透過重複練習與錯誤訂正，協助學生提升基本運算速度、正確率與熟練度。

## 使用方式

本專案目前為單一網頁程式，程式集中於 `index.html`。

目前透過 Vercel 部署成網頁，方便學生直接使用瀏覽器開啟練習。

支援手機、平板與桌機瀏覽器；其中手機與平板是主要使用情境。

使用者可在首頁選擇五種心算挑戰主題，並選擇 10 題、20 題或 30 題進行練習。

## 目前功能

* 提供五種心算挑戰主題。
* 隨機產生練習題目。
* 第一階段可直接輸入答案作答。
* 第一階段答錯後，會展開第二階段逐步訂正，引導學生完成正確解法。
* 支援分數等值答案判定。
* 支援畫面上的虛擬鍵盤，也支援電腦實體鍵盤輸入。
* 顯示目前題目進度，以及首次答對題目的星星標記。
* 結果頁會顯示總題數、首次答對題數與經引導後答對題數。
* 結果頁會顯示總作答時間及平均每題時間。
* 依不同題型的錯題數，產生本次測驗的盲點診斷。
* 同一道題在第二階段重複答錯，不會重複增加錯題數。
* 手機版支援動態視窗高度、裝置安全區與中間內容捲動，提升手機與平板操作穩定性。

## 畢氏定理特訓 V1

第五張卡片以穩定識別值 `pythagorean` 接入，與畫面排序分離；原四關出題器及作答流程保留。第一階段直接填正邊長，第二階段顯示畢氏公式及已知邊的平方，要求同時填完「平方和／差」與「實際邊長」。沿用鍵盤、星星、錯題只計一次、結果及耗時統計。

每份測驗的題型（求斜邊／求另一股／生活應用）與難度（基礎／中等／挑戰）均固定為 40%／40%／20%：10 題為 4／4／2，20 題為 8／8／4，30 題為 12／12／6。內部另存 `presentationType`、`solveType`、`difficultyBand`、三邊及未知邊，生活題不會被混算成純計算題。

| 難度 | 三邊題庫（公尺） | 計算重點 |
| --- | --- | --- |
| 基礎 | 3–4–5、6–8–10、9–12–15、5–12–13 | 小數值平方與由平方找正邊長 |
| 中等 | 12–16–20、15–20–25、10–24–26、8–15–17 | 兩位數平方、較大的平方和差 |
| 挑戰 | 18–24–30、7–24–25、20–21–29、16–30–34 | 跨百位的平方加減與相近邊辨識 |

斜邊不超過 30 的正整數三元組僅有 11 組，無法支援 30 題中的 12 道不重複純求斜邊題。因此依「原則上不超過 30」保留唯一例外 16–30–34（8–15–17 的兩倍），其餘三元組的斜邊均不超過 30。

出題先依有限配額表建立題型與難度格位，再從對應題庫無放回選取「三邊＋未知邊＋情境」；使用次數優先分散三元組、倍率、求股方向及情境，最後以隨機同分排序減少相似題相鄰。三種生活情境為長方形對角線、梯子靠牆、東向再北向移動，統一公尺；10 題涵蓋兩種不同情境，20／30 題涵蓋全部三種，情境數量差不超過一題。

圖形沿用 Canvas 直角三角形，增加長方形邊框、牆面梯子與東北移動路徑，均標示已知邊、x、直角及「示意圖，非依比例繪製」。新增平方加法、平方減法、生活建模三類診斷；診斷依錯題類型提出練習建議，不代表已精確判定學生的心理錯因。

本版不含根式輸入、非整數答案、逆定理或跨次紀錄。BUG-05～07 繼續以既有 TODO 管理。

## 目前已知限制

* 尚未儲存跨次練習的歷史答題與錯題紀錄。
* 盲點診斷只分析本次測驗。
* 不同類別錯題數相同時，目前只會顯示其中一個盲點。
* 桌機版仍以手機型窄版練習畫面為主。
* 程式目前集中於單一 `index.html`，功能增加後可能需要拆分。

## 本機測試

安裝 Node.js 24 LTS 後執行 `npm test`，不需安裝其他套件。GitHub Actions 會在 PR 與 main 更新時執行相同測試。

測試範圍、執行方式、限制及尚待修正的 Bug 請見 [tests/README.md](tests/README.md)。已知 Bug 使用可執行的 TODO 測試管理，不會阻擋其他正常功能的 CI 驗證。
