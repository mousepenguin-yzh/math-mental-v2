# 數感特攻隊

## 專案目的

這是一個提供國中學生練習數學心算的互動式網頁，主要使用者為國一升國二學生。

開發目的不是教授完整數學課程，而是透過重複練習，提高基本運算速度、正確率及熟練度。

## 使用方式

本專案為單一網頁程式，所有程式碼目前都放在 `index.html` 中。

目前透過 Vercel 部署成網頁分享給孩子們使用。

## 目前功能

* 首頁先以難度分四個主題選擇，再選練習題數
* 讓使用者輸入答案，判斷答案正確或錯誤，錯誤會顯示步驟計算過程填空引導學習
* 顯示練習結果，算分數，統計秒數與平均秒數，診斷今日盲點

## 目前已知問題

* 手機平板使用時，常常有畫面切到，按鈕按不到的問題
* 手機平板使用時，畫面配置略顯侷限，字略小
* 電腦使用的時候，畫面也是只集中在中間直畫面模擬手機

## 後續改善方向

* 優化手機操作介面
* 增加錯題或答題紀錄功能
* 視程式規模決定是否拆分 HTML、CSS 與 JavaScript
