## 挑戰卡片

- 第 3 題依序為 x−4、2x+1、x+1、x+4、2x−1、2x+5。審查用正解為第 1、2 張。
- 第 8 題依序為 x−4、3x−2、3x+2、x+4、x−2、3x−4。審查用正解為第 1、2 張。

## 訂正試讀

### 首一二次式　x²+8x+12

- 哪兩個整數的和為 8、積為 12？兩格一起送出，順序不限。
  - 先列常數絕對值的正因數配對。 → 積是正數，兩數同號。 → 逐對試加，留下和等於一次項係數的那一對。
  - 本步解法　2 與 6 相加為 8，相乘為 12，兩個條件都成立。
- 請自行輸入完整因式分解。

試填兩格

- 只填 2，另一格留白 → `numberPair / incomplete`
- 填 1、7，只有和吻合 → `numberPair / incorrect`
- 填 6、2，進入完整分解輸入 → `ans2 / incomplete`

### 係數與 x 的公因式　4x²+10x

- 這兩項的最大公因式（含數字與 x）是多少？
  - 先找兩個係數的最大公因數，再看兩項共同含有的 x。 → 找出能同時整除 4 和 10 的最大正整數。 → 數字最大公因數是 2，加上兩項都有的 x，合起來寫成 2x。
  - 本步解法　同時能整除 4 和 10 的最大正整數是 2，且兩項都含有 x，所以最大公因式是 2x。
- 請自行輸入完整因式分解。

試填最大公因式

- 只填 2（漏寫 x） → `gcf / incorrect`
- 填 2x+1（非單項式） → `gcf / invalid`
- 填 2x，進入完整分解輸入 → `ans2 / incomplete`

### 十字交乘　2x²−7x−4

- 選兩張卡片，依「首項 → 常數 → 交叉項係數」檢驗配對。
  - ① 先看首項：兩張卡的 x 項相乘要等於 2x²，所以要選一張 2x 開頭、一張 x 開頭的卡。 → ② 再看常數：兩張卡的常數相乘要等於 -4（積為負，兩常數異號）。 → ③ 最後驗交叉項：外項係數加內項係數要等於 -7；若算出的數只差正負號，試著把兩張卡的常數正負號互換。
  - 本步解法　選「2x+1」和「x−4」：首項 2x×x=2x²，常數 (1)×(-4)=-4，交叉項係數 -8+(1)=-7。
- 請自行輸入完整因式分解。

試檢驗卡片

- 選 x−4、x+1，首項不符 → `crossCheck / leading-mismatch`
- 選 x+4、2x−1 並正確算出交叉項 7，符號不符題目 -7 → `crossCheck / middle-mismatch`
- 改選 2x+1、x−4 並算出交叉項 -7，進入完整分解輸入 → `ans2 / incomplete`

試作時請記下需要紙筆的題號，特別留意負數和積配對、先提公因數後辨認平方差，以及六張卡片能否靠交叉乘積有效排除。可先遮住答案與解法，再逐條閱讀提示。
