## 挑戰卡片

- 第 3 題依序為 x−4、2x+1、x+1、x+4、2x−1、2x+5。審查用正解為第 1、2 張。

## 訂正試讀

### 首一二次式　x²+8x+12

- 哪兩個整數的和為 8、積為 12？兩格一起送出，順序不限。
  - 先列常數絕對值的正因數配對。 → 積是正數，兩數同號。 → 逐對試加，留下和等於一次項係數的那一對。
  - 本步解法　2 與 6 相加為 8，相乘為 12，兩個條件都成立。
- 請自行輸入完整因式分解。

試填兩格

- 只填 2，另一格留白 → `numberPair / incomplete`
- 填 1、7，只有和吻合 → `numberPair / incorrect`
- 填 6、2，進入完整分解輸入 → `ans2 / incomplete`

### 係數與 x 的公因式　4x²+10x

- 兩個係數的最大公因數是多少？
  - 先看數字部分。 → 列出首項係數的因數。 → 由大到小找也能整除一次項係數的數。
  - 本步解法　同時能整除 4 和 10 的最大正整數是 2。
- 提出 2x 後，括號裡的常數是多少？
  - 找出每一項都有的 x。 → 一次項除去公因式後只剩常數。 → 把一次項係數 10 除以 2，保留正負號。
  - 本步解法　10x ÷ (2x) 的商是 5。
- 請自行輸入完整因式分解。

### 十字交乘　2x²−7x−4

- 選出相乘能得到題目的兩張卡。
  - 先看兩張卡的 x 項相乘能否得到首項。 → 再檢查兩個常數相乘的大小和正負號。 → 若有多組都符合，檢查兩個交叉乘積的係數和是否為 -7。
  - 本步解法　選「2x+1」和「x−4」。首項係數是 2，常數積是 -4，交叉項的係數和是 -7。
- 用「2x+1」的 2x 乘「x−4」的常數。所得 x 項係數是多少？
  - 從題目指定的 x 項沿對角線找到另一張的常數。 → 先看兩數的符號，決定乘積的正負。 → 算 2 × (-4)，填入帶符號的係數。
  - 本步解法　係數 2 乘常數 -4，得到 -8。
- 用「2x+1」的常數乘「x−4」的 x 項。所得 x 項係數是多少？
  - 改沿另一條對角線相乘。 → 另一張卡的 x 係數是 1。 → 用一次項係數減去剛算出的交叉乘積係數。
  - 本步解法　另一個係數是 1 × 1 = 1，兩者相加得到 -7。
- 請自行輸入完整因式分解。

試選卡片

- 選 x+4、2x−1，留在選卡步重新配對 → `cardPair / wrong-pair`
- 改選 2x+1、x−4，開始計算已確認卡片的交叉項 → `crossA / incomplete`
