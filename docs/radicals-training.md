# 根式運算特訓 V1：題庫與驗收設計

第六關識別值為 radicals，沿用既有 buildQuestions、兩階段作答、精確判定與根號鍵盤。原五關識別值、順序、出題及計分不變；BUG-05～07 維持獨立 TODO。

## 固定配額與多樣性

| 題數 | 化簡／加減／乘除 | basic／medium／challenge |
| --- | --- | --- |
| 10 | 3／4／3 | 4／4／2 |
| 20 | 6／8／6 | 8／8／4 |
| 30 | 9／12／9 | 12／12／6 |

以題型×難度的配額格位從有限結構候選庫無放回選取，不抽任意大整數。questionKey 以原始係數、被開方數與運算建立；加法、乘法先排序兩個運算元，交換後仍視為同題。加減與乘除各至少有兩個格位，每個相關難度格均有兩種運算候選；選題優先使用尚未出現的運算，因此每場包含加、減、乘、除。沒有重試失敗後放寬配額或去重的路徑。

運算覆蓋後依子類與答案使用次數降低重複，排序再分散相同子類、難度與答案家族。這些分散屬偏好，不是額外僵硬配額；零結果只來自一項化簡後相消的少量模板。每場回傳深複本，題目生命週期狀態不污染候選庫。固定 Math.random 種子即可重現，與現有測試一致；正式 UI 不新增種子設定。

## 模板、預期心算策略與難度

| 子類 | 難度 | 結構限制與心算策略 |
| --- | --- | --- |
| square-factor | basic | n∈2、3、4、5、6、8、10；r∈2、3、5。辨識熟悉 n²×r，取出 n。 |
| large-square | medium | n∈12、15、20；r∈2、3、5；被開方數≤1200。辨識 144、225、400 的簡單倍數。 |
| hidden-square | challenge | n∈7、11、14；r∈2、3、5。辨識非整十平方 49、121、196 的小倍數；不要求質因數分解或連續試除。 |
| outer-coefficient | medium | 外係數2或3，n∈2～5。取出平方因數後，乘一個小外係數。 |
| perfect-square | basic | n∈2～10、12、15、20。直接反查平方根。 |
| direct | basic | 同類方根，係數1～7。僅合併係數，兼有加法及正／負減法。 |
| one-simplify | medium | 一項取出2～5，再與1、3、5、7合併；無零結果。 |
| both-simplify | challenge | 兩項取出2～6後合併，同一 r∈2、3、5。將辨識兩個熟悉平方視為一組轉換，再合併係數；工作記憶負擔需人工審查。 |
| zero | medium | √(n²r)−n√r，n∈2～5。化簡後辨識相同量相消，避免只用完全一樣的兩項。 |
| integer-product | basic／medium | √r×√(n²r)，n∈1～4。n=1直接同根相乘為basic，其他先化簡為medium。 |
| radical-product | basic／medium | √(gu)×√(gv)，g∈2、3、5；(u,v)從(1,2)、(1,3)、(1,5)、(2,3)、(2,5)、(3,5)挑選。共同 g 配成平方；其中一個運算元就是 g 為basic，兩邊皆須拆出共同 g 為medium。 |
| outer-product | medium／challenge | 外係數2；同根配對或一邊直接可配平方為medium，兩邊皆須找共同因數後再乘外係數為challenge。不先做長乘法。 |
| quotient | basic／medium | √(bk²r)÷√b，b∈2、3、5、6，k∈2、3、4、5、10、15，被開方數≤900。先除再開根號；r=1且k≤5為basic，較大熟悉平方或需保留根式為medium。 |
| outer-quotient | challenge | √(bk²)÷(2√b)，b∈2、3、5，k∈4、6、8，被開方數≤600。先除成完全平方數，再開根號並折半。不引入根式商的額外化簡。 |

難度依辨識／轉換策略分類，並非按被開方數門檻分類。所有輸入根號外係數≤7（加減）或≤3（其餘）；平方因數的根≤20。最終根式係數絕對值≤20，整數結果≤40。化簡使用的 r 為2、3、5；乘法可能留下6、10、15。被開方數≤1200只是模板產生後的邊界，不代表數字越大越難。

心算通常是一到兩個主要轉換：例如兩項化簡是辨識兩個小平方後合併；帶外係數乘法則是配同根後乘小係數。這是設計預期，不能當作實際學生皆能兩步完成的證明。

## 訂正與精確答案

所有最終答案（包含整數與零）使用 radical＋simplest；中間步驟使用 integer。第一階段不顯示 mentalStrategy，該欄僅供樣本審查；第二階段使用簡短觀念提示及必要填空。

- 化簡填平方因數與最後答案；完全平方數直接填最後答案。
- 已同類直接填合併係數與最後答案；一項化簡2格，兩項化簡3格。
- 乘法優先化為同根，或把共同因數配平方；不一律要求先算完整被開方數乘積。
- 除法先填根號內的整數商，最後填最簡答案；外係數除數加括號避免語意不清。
- 完全平方數及直接 √r×√r 僅1格：這兩種題只有一次反查／配對，增加中間格會要求重填相同整數。其餘一般2格，兩項化簡3格。

答案、提示與訂正由同一道題目的運算元建立，不另外維護訂正題庫。沿用 validateTypedAnswer(raw, spec)，未最簡留在原階段重試並失去首次星星；格式不合法／不完整保留首次資格。只統計真正進入第二階段者為引導題。三大類錯題診斷提供觀念建議，不宣稱能精確判定心理錯因。

## 驗收與人工審查

- npm test：既有五關完整回歸，以及根式10／20／30題各100個固定種子的6,000題獨立驗算。
- 獨立 oracle 從可見題面解析運算元，對平方量做質因數指數分解，重新求符號、係數、無平方因數部分及每個訂正值；不呼叫正式正規化或讀預存答案作為求解依據。
- 正式判定器另接收獨立算出的最簡文字，以確認答案規格與輸入能力吻合；不以浮點近似比較。
- [180題審查樣本](radicals-review-samples.md) 包含9場、固定種子、答案、子類、難度、心算策略及所有子類訂正。以 node scripts/generate-radical-samples.cjs 重建，加 --check 驗證沒有過期。
- 人工仍須審查平方辨識負擔、兩項化簡／外係數題的步驟感、提示品質及手機／平板實際輸入與版面。數學通過不等於教學品質已通過；PR 在人工驗收前不合併。
